## Dataset

This project uses the **Olist Brazilian E-Commerce Public Dataset**.

Download the dataset from Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

After downloading, extract the files and place all CSV files inside:

```
data/raw/
```

The raw dataset files are not included in this repository because they are ignored using `.gitignore`.
